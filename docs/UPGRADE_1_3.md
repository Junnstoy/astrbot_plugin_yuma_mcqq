# 更新到 1.3.0

更新代码后保留原插件数据目录，先备份配置与数据库。本次更新不会自动导入旧库、修改服务器 ID 或向游戏发送奖励。绑定迁移与四种签到回复沿用 [1.2 的使用说明](UPGRADE_1_2.md)。

## 引用标签文字

在“连接与群服 → 编辑与开关”中，引用悬浮内容之前新增“{reply} 标签模板”。填入：

```text
(回复 @{sender})
```

`{sender}` 是原消息作者，标签会出现在前缀 `{reply}` 指定的位置。留空使用 `[回复 {sender}]`。此项是文字模板，颜色由“引用标签颜色”控制，悬浮仍默认三行原作者、原内容、`Date: 原时间`。间距可在标签或前缀中显式填写。

## 列表分页与网页解绑

绑定、点数账户、流水、签到、运行记录和管理审计按数据库分页查询，默认每页 10 条，可切换 20 / 50 / 100 条。支持翻到旧记录，作用域先过滤再统计总数。迁移预览和帮助列表也有分页；刷新保留页码，删除导致页码越界时返回最后一页。

AstrBot 内嵌页面禁止浏览器原生确认框，旧解绑按钮因此可能完全没有发出请求。本版改用页面内确认：点击“管理员解绑”，核对 QQ 与 MC 名，再点击“确认解绑”。取消不会执行；服务端拒绝时在表单显示原因。服务器、路由、指令和商品删除同样采用页面内确认，框架沙箱限制不变。

## 性能图坐标与 ticks

GUI 图表显示纵轴数值刻度、单位及时间范围。MSPT 的原始含义是每 tick 耗时，以毫秒表示；按本次需求，GUI 与“性能图”PNG 将数值除以 50 后显示为 `ticks`，并注明 **1 tick = 50 ms**。例如 12 ms 显示 0.24 ticks。该值是固定 50 ms 标准下的耗时换算，不是实时 TPS 或 tick 数量统计。

数据库继续保存原始毫秒采样，聊天 `mspt` 指令仍回复实际 RCON 文本。缺失样本保留空缺，不填 0。[Paper MSPT 定义](https://docs.papermc.io/paper/reference/commands/#mspt)

## 修改服务器 ID

打开“连接与群服”，在服务器行点击“修改 ID”。普通“编辑”表单中的 ID 仍为只读，避免把新 ID 当成另一个服务器新增。新 ID 使用字母、数字、下划线或短横线，长度 1–64，不能与现有服务器或其他历史数据冲突。

专门操作会同步路由、自定义命令目标、绑定及验证码、业务快照与历史、运行记录和性能历史，余额、冷却和订单状态不变。QueQiao 鉴权名称和显示名称不随 ID 改动。正在进行的操作先等待完成；超时取消的外部请求保留未知状态，不自动重发。连接会短暂重新建立。

迁移用持久操作日志逐库完成，可中断后继续。出现“迁移尚未完成”时，新的业务操作暂停；重试原来的 ID 修改请求，或重载插件让启动恢复。不要删除 `server-rename.json`，也不要在迁移中手改配置。旧库原始归档保留原文。修改 ID 后，之前打开的旧库导入计划需要重新预览。

## 帮助图片、说明、显隐与顺序

打开“指令与帮助 → 帮助展示与说明”：

- “帮助回复设置”中的“帮助使用图片回复”默认开启；关闭后 `mc帮助` 返回文字。图片生成失败会回退同份文字。
- 默认及自定义指令都有“编辑说明与排序”；说明留空恢复默认，排序数字越小越靠前。
- “从帮助隐藏 / 在帮助显示”只影响帮助展示。是否允许执行仍由管理行为的启停与权限控制。
- “上移 / 下移”可直接调整完整帮助顺序。图片和文字采用相同的顺序、说明和显示规则。

帮助使用管理行为当前生效的名称、别名以及会话唤醒前缀；停用、隐藏或当前用户无权使用的指令不会出现。说明可编辑不等于命令参数可任意变化。图片内容过长会分成多张，不截断后面的指令。

图片需要运行 AstrBot 的系统提供中文字体。Linux/Docker 可在机器人环境安装 `fonts-noto-cjk`（Debian/Ubuntu），或将 Noto Sans CJK / 思源黑体安装到系统字体目录；Windows 自动查找微软雅黑或黑体。缺少字体时自动回文字，不返回乱码图片。插件不会联网下载字体，也不附带 Windows 字体。

完整默认帮助样张（仅内置命令）：[第 1 页](screenshots/help-example-1.png)、[第 2 页](screenshots/help-example-2.png)。实际回复会采用你的名称、说明、权限与显示设置。

具体验证范围见 [验证记录](VALIDATION.md)。以上变更均未自动部署到生产服务。
